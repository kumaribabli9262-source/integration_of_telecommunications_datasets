# Integration of telecommunications datasets

## Overview

This project demonstrates how multiple telecommunications datasets are integrated and prepared for analysis using IBM SPSS Modeler. It covers essential data preprocessing and transformation techniques applied through SPSS nodes.

## Objective

To merge, clean, and sample telecom data for predictive analytics using various SPSS operations.

## Tools Used

Software: IBM SPSS Modeler

## Datasets:

- telco_x_call_data_q1.sav

- telco_x_call_data_q2.sav

- telco_x_customer_data.xlsx

- telco_x_products.dat

- telco_x_tariff.dat

## Key Steps

- Append: Combine multiple quarterly datasets.

- Sort: Arrange records by customer_id and month.

- Aggregate: Summarize data using key fields.

- Distinct: Remove duplicate records.

- Merge: Join datasets based on key attributes.

- Type & SetToFlag: Define and transform data fields.

- Sample: Extract every 3rd record for analysis.

## Outcome
A single integrated, clean, and sampled telecom dataset ready for modeling and predictive analysis.
